# 基金小笺 · Fund Note

**点击浏览器工具栏，用一张小笺查看基金持仓和行情日收益。**

基金小笺是一款个人开发的 Chrome 扩展，提供 Popup 弹出面板、完整持仓视图和 CSV 导入导出。持仓保存在浏览器本地，无需注册软件账号。

当前版本：**Chrome 1.0 测试版（1.0.0）**。界面为中文，提供中英文文档。尚未上架 Chrome Web Store，需通过开发者模式加载。

## 主要功能

- **Popup 小笺**：显示行情日总收益、每只基金的该日收益和收益率；总资产单独展示。默认保留3只基金的空间，更多持仓增加高度后滚动。
- **原生收益角标**：保留原图标，盈利红底白字、亏损绿底白字；显示绝对金额的四舍五入整数。悬停查看带正负号的完整金额、行情日期和更新时间。角标与面板使用同一计算口径。
- **完整持仓视图**：查看份额、成本、确认净值、估值和持仓收益，点击“修改”后编辑，独立保存或取消。
- **指数行情**：默认单行滚动；鼠标停留1秒展开紧凑双列行情，移开渐隐收起。
- **CSV 与自动备份**：导入前校验并预览，确认后替换；每次修改前最多保留最近10份本地备份，可下载为 CSV。
- **刷新保护**：按市场时段刷新，共用缓存、请求合并和手动刷新冷却。

## 下载和安装

1. 打开 [Chrome 1.0 测试版 Release](https://github.com/power32m/fund-note/releases/tag/chrome-v1.0.0-test)，下载 **FundNote-Chrome-1.0.0-test.zip** 与 **SHA256SUMS.txt**。
2. 按[安全说明](SECURITY.md)核对 SHA256，解压 ZIP，并保留解压目录。
3. 在 **Chrome 127 或更新版本**打开 `chrome://extensions`，开启“开发者模式”。
4. 点击“加载已解压的扩展程序”，选择解压后的 **chrome-extension** 文件夹。
5. 从浏览器拼图菜单固定“基金小笺”，点击图标，添加自己的基金代码、份额和每份成本。

首次安装为空持仓。若更新已有测试版，应覆盖原安装目录中的运行文件，然后在扩展管理页点击“重新加载”；**不要先卸载**。商店版将来可能使用不同扩展ID，迁移前请导出 CSV。

GitHub 自动生成的 **Source code (zip/tar.gz)** 只包含这个文档仓库，不能作为扩展安装包。详细步骤及截图见[图文教程](docs/CHROME.zh-CN.md)。

## 收益与刷新口径

“行情日收益”与“持仓总收益”是不同指标。该日收益按持有份额和当日净值变化估算；总资产与确认持仓收益按最新确认净值计算。盘中估值可能偏离最终净值，成本、精度、分红、费用、汇率和平台算法也可能造成差异。软件不记录完整交易、分红或费用流水，不执行交易。

今日行情尚未发布时，显示带日期的“最近行情日收益”；今日数据到达后自动切回，不混合不同日期汇总。部分数据缺失时显示覆盖提示。角标数字省略正负号和小数，以底色表示盈亏；完整金额以面板和悬停提示为准，较长金额受Chrome角标空间限制。

活跃交易时段页面通常15秒尝试刷新，后台通常60秒；休市降频。估值和指数手动刷新至少间隔10秒，确认净值通常5分钟更新、手动至少间隔60秒。请求间隔不代表数据源的更新速度；浏览器休眠、关闭和网络状态会影响后台运行。交易日历覆盖2026年，其他年份回退到工作日与常规时段。
